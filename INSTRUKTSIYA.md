# Покрокова інструкція: від коду до живого сайту

Ніде тут не знадобиться командний рядок — усе робиться клацанням у браузері
або в програмі з кнопками. Проходьте етапи по порядку, кожен — окрема
"зупинка", можна робити не все за раз.

- [ ] Етап 1 — код на GitHub
- [ ] Етап 2 — база даних на Supabase
- [ ] Етап 3 — Telegram-бот
- [ ] Етап 4 — сайт на Netlify
- [ ] Етап 5 — перевірка, що все працює

---

## Етап 1. Покласти код на GitHub

GitHub — це "хмара" для зберігання коду сайту. Netlify (етап 4) буде брати
код звідти й автоматично публікувати. Далі, коли я щось міняю в коді,
ви просто оновлюєте файли тут же — і сайт сам переопублікується.

1. Зайдіть на **github.com** → "Sign up" → створіть безкоштовний акаунт
   (email + пароль, підтвердження поштою).
2. Завантажте й встановіть **GitHub Desktop** — desktop.github.com
   (це програма з кнопками, замінює весь командний рядок). Увійдіть у ній
   тим самим акаунтом GitHub.
3. У GitHub Desktop: **File → New repository**.
   - Name: `course-platform`
   - Local path: оберіть будь-яку зручну теку на комп'ютері (наприклад, Робочий стіл)
   - **Create repository**
4. Розпакуйте архів `course-platform.zip`, який я вам надсилала. Всередині
   архіву є тека `course-platform` — відкрийте її, виділіть **усі файли
   всередині** (не саму теку, а її вміст) і скопіюйте.
5. Вставте (Paste) ці файли в ту теку, яку GitHub Desktop щойно створив
   на кроці 3 — з підтвердженням заміни, якщо запитає.
6. Поверніться в GitHub Desktop — унизу зліва побачите поле для коміту
   (це як "зберегти версію"). Напишіть будь-що, наприклад "перша версія",
   і натисніть **Commit to main**.
7. Зверху натисніть **Publish repository**. Можна залишити пташку
   "Keep this code private" — приватний репозиторій, ніхто зайвий не побачить.

Готово — код тепер у вашому акаунті на GitHub. Перевірити: зайдіть на
github.com у свій акаунт, там має з'явитись репозиторій `course-platform`
з усіма файлами.

**Коли я надсилатиму оновлений код надалі** — робитимемо кроки 4-7 ще раз
(замінити файли → Commit → Push origin), і Netlify сам підхопить зміни.

## Етап 2. База даних на Supabase

1. Зайдіть на **supabase.com** → "Start your project" → увійдіть через
   GitHub-акаунт (простіше) → **New project**.
   - Задайте назву, придумайте пароль до бази (збережіть його кудись,
     хоча в щоденній роботі він не знадобиться) → оберіть регіон ближче
     до України (наприклад, Frankfurt) → **Create project**. Зачекайте
     1-2 хвилини, поки Supabase все підготує.
2. Зліва в меню: **SQL Editor** → **New query**.
3. Відкрийте в моєму архіві файл `supabase/schema.sql`, скопіюйте
   **весь** його вміст, вставте у вікно SQL Editor → натисніть **Run**.
   Має з'явитись "Success. No rows returned" — це означає, що всі таблиці
   створено.
4. Зліва: **Project Settings → API**. Тут три значення, які знадобляться
   на етапі 4 (Netlify):
   - `Project URL`
   - `anon public` ключ
   - `service_role` ключ (не показуйте його нікому й не публікуйте — він
     дає повний доступ до бази)
5. Зліва: **Storage** → **New bucket** → створіть два бакети (це "теки"
   для файлів): `chat-attachments` і `homework`. Для обох увімкніть
   **Public bucket**.

Поки що зупинимось тут — увімкнути себе як адміна ми зробимо на етапі 5,
після того як сайт уже буде опублікований і ви зможете один раз увійти.

## Етап 3. Telegram-бот

1. У Telegram знайдіть **@BotFather**, напишіть йому `/newbot`.
2. Дайте боту ім'я й унікальний username (закінчується на `bot`,
   наприклад `myacademy_bot`).
3. BotFather надішле **токен** — довгий рядок виду `123456:AAH...`.
   Збережіть його, знадобиться на етапі 4.
4. Придумайте будь-який випадковий рядок (наприклад, `xk29Ptqz81`) —
   це буде `TELEGRAM_WEBHOOK_SECRET`, теж знадобиться на етапі 4.
   Просто пароль для перевірки, що повідомлення справді від Telegram.

`TELEGRAM_ADMIN_CHAT_ID` (ваш особистий chat_id) отримаємо на етапі 5,
після того як напишете щось своєму боту.

## Етап 4. Публікація на Netlify

1. Зайдіть на **netlify.com** → увійдіть через GitHub-акаунт.
2. **Add new site → Import an existing project → Deploy with GitHub**.
3. Оберіть репозиторій `course-platform` (той, що на етапі 1). Netlify
   сам розпізнає, що це Next.js — налаштування збірки міняти не треба.
4. Перш ніж тиснути "Deploy", розгорніть **Environment variables** і
   додайте по одному (Key / Value):

   | Key | Value |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Project URL з етапу 2 |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon public ключ з етапу 2 |
   | `SUPABASE_SERVICE_ROLE_KEY` | service_role ключ з етапу 2 |
   | `TELEGRAM_BOT_TOKEN` | токен з етапу 3 |
   | `TELEGRAM_WEBHOOK_SECRET` | випадковий рядок з етапу 3 |
   | `TELEGRAM_ADMIN_CHAT_ID` | поки що впишіть `0`, зміните на етапі 5 |
   | `NEXT_PUBLIC_SITE_URL` | поки що впишіть `https://placeholder.netlify.app`, зміните на етапі 5 |

5. **Deploy site**. Зачекайте кілька хвилин — Netlify видасть вам адресу
   типу `https://дивна-назва-123.netlify.app`. Можна одразу перейменувати
   на щось зрозуміліше: **Site configuration → Change site name**.

## Етап 5. Довершити й перевірити

1. Скопіюйте фінальну адресу сайту (з етапу 4) → Netlify →
   **Site configuration → Environment variables** → відредагуйте
   `NEXT_PUBLIC_SITE_URL`, вставивши цю адресу → **Save**, а тоді
   **Deploys → Trigger deploy**, щоб зміна набула сили.
2. Відкрийте ваш сайт → `/login` → введіть свій email → перейдіть за
   посиланням із листа. Ви щойно зареєструвались як перша учасниця.
3. У Supabase → **SQL Editor** → виконайте:
   ```sql
   update profiles set role = 'admin' where email = 'ваш-email@приклад.com';
   ```
   Тепер при вході на сайт ви потрапите в адмінку, а не в кабінет учениці.
4. Напишіть щось своєму боту в Telegram (будь-яке повідомлення), тоді
   відкрийте в браузері (підставивши токен з етапу 3):
   ```
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   ```
   У відповіді знайдіть `"chat":{"id":ЧИСЛО, ...}` — це число і є
   `TELEGRAM_ADMIN_CHAT_ID`. Впишіть його в Netlify (той самий розділ
   Environment variables), знову Trigger deploy.
5. Там само відкрийте (підставивши свої значення):
   ```
   https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://ваш-сайт.netlify.app/api/telegram/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
   ```
   Побачите `{"ok":true,...}` — Telegram-бот підключено.

**Готово — сайт живий.** Наповнення курсів (поки без окремої форми, через
Supabase Table Editor) — окрема тема, повернемось до неї, коли будете
на цьому етапі.
