# Модель даних курсу

## Урок

| Поле | Тип | Значення |
|---|---|---|
| `id` | `uuid` | Ідентифікатор уроку |
| `course_id` | `uuid` | Курс, до якого належить урок |
| `parent_lesson_id` | `uuid \| null` | Батьківський урок; `null` — головний рівень |
| `short_label` | `text` | Коротка мітка: `4`, `4.1` тощо |
| `title` | `text` | Назва уроку |
| `description` | `text` | Опис уроку |
| `order_index` | `integer` | Порядок у курсі |
| `presentation_url` | `text` | Необов’язкове посилання на презентацію уроку |

## Доступ до наступного уроку

Ці поля належать поточному уроку й описують умову відкриття **наступного** уроку.

| Поле | Тип | Значення |
|---|---|---|
| `next_lesson_access_rule` | `text` | `free`, `after_submission`, `after_review`, `after_delay`, `scheduled` |
| `next_lesson_delay_hours` | `integer` | Затримка для режиму `after_delay` |
| `next_lesson_delay_days` | `integer` | Кількість днів для режиму `scheduled` |
| `next_lesson_unlock_time` | `time` | Час відкриття для режиму `scheduled`, за замовчуванням `09:00` |

Для курсу є також `short_label` — коротка мітка, яку адміністратор задає самостійно й яка показується на картці курсу.

## Домашнє завдання

| Поле | Тип | Значення |
|---|---|---|
| `homework_enabled` | `boolean` | Чи є в уроці ДЗ |
| `homework_description` | `text` | Текст завдання |
| `homework_require_text` | `boolean` | Текст обов’язковий для здачі |
| `homework_require_photo` | `boolean` | Фото обов’язкове для здачі |
| `homework_require_video` | `boolean` | Відео обов’язкове для здачі |

Усі три формати незалежні. Якщо ввімкнено кілька прапорців, учениця повинна додати кожен із них. Якщо жодного — достатньо будь-якої непорожньої відповіді.

`homework_type` — застаріле поле. Воно збережене в базі для сумісності зі старими даними, але новий код його не використовує.

## Матеріали

- `videos` — список відео конкретного уроку.
- `presentations` — загальна презентація курсу.
- `presentation_url` — посилання на презентацію конкретного уроку.
- Для загальної й урокової презентації, а також відео уроку, R2-метадані зберігають ключ файлу, назву й MIME-тип. Сам файл завжди приватний.

## Прогрес учениці

`lesson_progress` зберігає перше відкриття уроку, факт здачі ДЗ і результат перевірки. За цими даними відкривається наступний урок у режимах «після здачі», «після перевірки», «через час» та «за графіком».

## Доступ до курсу до першого входу

`pending_students` і `pending_course_access` зберігають email та вибрані курси без надсилання auth-листа. Під час першого входу через Google тригер профілю переносить ці доступи в `course_access` і видаляє очікувальний запис.
