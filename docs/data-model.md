# Модель даних курсу

## Урок

| Поле | Тип | Значення |
|---|---|---|
| `id` | `uuid` | Ідентифікатор уроку |
| `course_id` | `uuid` | Курс, до якого належить урок |
| `parent_lesson_id` | `uuid \| null` | Батьківський урок; `null` — головний рівень |
| `short_label` | `text` | Коротка мітка: `4`, `4.1` тощо |
| `title` | `text` | Назва уроку |
| `description` | `text` | Опис уроку |
| `order_index` | `integer` | Порядок у курсі |

## Домашнє завдання

| Поле | Тип | Значення |
|---|---|---|
| `homework_enabled` | `boolean` | Чи є в уроці ДЗ |
| `homework_description` | `text` | Текст завдання |
| `homework_require_text` | `boolean` | Текст обов’язковий для здачі |
| `homework_require_photo` | `boolean` | Фото обов’язкове для здачі |
| `homework_require_video` | `boolean` | Відео обов’язкове для здачі |

Усі три формати незалежні. Якщо ввімкнено кілька прапорців, учениця повинна додати кожен із них. Якщо жодного — достатньо будь-якої непорожньої відповіді.

`homework_type` — застаріле поле. Воно збережене в базі для сумісності зі старими даними, але новий код його не використовує.

## Матеріали

- `videos` — список відео конкретного уроку.
- `presentations` — загальна презентація курсу.
- Презентація та завантажене відео конкретного уроку потребують окремих полів метаданих після підключення R2 до редактора матеріалів.
