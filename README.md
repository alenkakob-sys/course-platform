# Сайт курсів — проста структура (без збірки)

Звичайні HTML/CSS/JS-файли, без npm і без збірки. Хоститься на GitHub
Pages. Детальні кроки переходу — у файлі `MIGRATION.md`, який надіслано
окремо.

## Модульність

Кожна частина функціоналу — окремий файл. Якщо треба щось поправити,
міняється лише відповідний файл:

- `js/config.js` — ваші реальні адреси/ключі (єдине, що ви самі редагуєте)
- `js/supabaseClient.js` — з'єднання з базою
- `js/auth.js` — вхід/вихід, перевірка ролі
- `js/chat.js` — дані чату (треди, повідомлення, непрочитані)
- `js/components/chat-panel.js` — вигляд і поведінка чату
- `js/components/homework-field.js` — домашнє завдання
- `js/pages/*.js` — логіка кожного окремого екрана
- `css/style.css` — кольори, шрифти, відступи

## Сторінки

- `login.html` — вхід (Google або email)
- `courses.html` — вибір курсу (учениця)
- `course.html?course=ID` — сам курс: відео, опис, ДЗ, чат
- `admin.html` — список учениць (адмінка)
- `admin-manage.html` — керування курсами
- `admin-manage-course.html?course=ID` — редагування курсу й уроків
- `admin-manage-students.html` — запрошення учениць, доступ до курсів
